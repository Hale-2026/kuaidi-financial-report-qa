## 判定口径（对应课程第三课 P61–63、P90–92）

- **正确** = 该题全部证据义务都在答复里被正确作答；
- **部分正确** = 覆盖 1 项以上、但未覆盖全部；
- **错误** = 一项都没覆盖；
- 「覆盖」= 标准答案的数值出现在答复中，**且**归宿到正确的公司 / 口径 / 报告期。

**召回命中与答题正误是两个独立的量**：`eval_scores.json` 的召回层是"证据找回来没有"
（宽松上界），答案层才判"数值答对没有"。
